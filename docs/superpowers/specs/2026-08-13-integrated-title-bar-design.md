# 一体式标题栏设计

日期：2026-08-13

## 目标

把当前上下分离的 Windows 原生标题栏和应用内顶部导航合并为一条 48px 一体式标题栏。保留 Windows 原生窗口控制按钮，不增加与现有业务无关的搜索框或自绘窗口按钮。

## 布局

- 窗口内容通过 `ExtendsContentIntoTitleBar` 延伸到系统标题栏区域。
- 根布局顶部固定 48px，左侧固定 224px，与展开侧栏宽度一致；该区域显示 OpenSynapse Logo、名称和简短副标。
- 顶部右侧显示现有面包屑 `OpenSynapse / 当前页面`，并为系统最小化、最大化、关闭按钮预留右侧空间。
- `NavigationView` 的品牌头从 PaneHeader 移到根标题栏，菜单内容从 48px 标题栏下方开始，避免品牌重复。
- 页面内容不再包含第二条内部标题栏，现有页面滚动区域继续从统一标题栏下方开始。

## 窗口行为

- 使用 `SetTitleBar(AppTitleBar)` 注册统一标题栏的拖拽区域。
- 标题栏内不放交互式应用控件，因此整个非系统按钮区域可拖动窗口。
- 最小化、最大化、关闭继续由 Windows 管理，保留系统命中区域、键盘行为和辅助功能。
- 深色标题栏颜色继续复用当前固定深色配置。
- `NavigationView.IsTitleBarAutoPaddingEnabled` 关闭，避免框架再次添加顶部留白。

## 范围边界

- 不增加搜索、返回按钮、自绘窗口按钮或额外导航层。
- 不修改设备、遥测、Profile、托盘生命周期或硬件控制逻辑。
- 不改变侧栏 224px 宽度和现有页面名称。

## 验证

- x64 App 构建要求 0 warning、0 error。
- 运行全部非硬件测试，不设置 `OPENSYNAPSE_HARDWARE_TEST`。
- 启动应用确认顶部只有一条 48px 标题栏，品牌、面包屑和原生窗口按钮处于同一水平层。
- 确认标题栏空白处可拖动，双击可最大化或还原，窗口按钮可见且不遮挡面包屑。
- 检查概览、设备、配置和诊断页面无额外顶部空白或内容遮挡。
