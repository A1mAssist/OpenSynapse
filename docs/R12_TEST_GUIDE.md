# r12 测试包验证指南

- 包：`artifacts/OpenSynapse-1.6.0-beta-gapfix-r12-20261031.zip`
- 版本：`1.6.0+0b57042`（当前 `main`）
- 构建依据：2141 测试通过 / 0 失败，Release win-x64 0 警告 0 错误
- 性质：测试包，不是正式发布；没有对应机型的实机验证记录

## 通用步骤

1. 先从托盘退出正在运行的旧实例。
2. 解压到新目录，直接运行 `OpenSynapse.App.exe`，不要覆盖现有安装目录。
3. 每测一项，记录：设备型号 / PID、操作步骤、期望结果、实际结果。

## 本机可用的测试目标

- Razer Viper V3 HyperSpeed（`00B8`）已连接：验证设备卡是否出现，电量 / DPI / 轮询率是否可读。
- Razer Blade 16 2025（`02C6`）已连接：用于启动冒烟和既有 Blade 页回归。
- 测试前先从托盘退出正在运行的旧实例（例如 powerwall 测试包）；否则 r12 会转发给旧实例，测到的不是新代码。

## 重点验证项

| 场景 | 步骤 | 期望 |
|---|---|---|
| 管理员启动 | 先普通启动到托盘，再右键“以管理员身份运行” | 设备页能正常探测；旧版托盘会提示先退出旧实例 |
| Blade 16 2023（029F） | 打开风扇卡片和启动动画卡片 | 风扇曲线存在，写入上限 5300 RPM；启动动画卡片隐藏 |
| 黑寡妇 V4 Pro / V4 75% | 选固定灯光，再选白色 | 固定效果可下发；白色不再显示成黑色 |
| 矩阵键盘 | 点“填充当前颜色”，再应用整帧 | 整片矩阵按当前颜色填充 |
| AMD Blade | 打开性能页，观察独显监控和启动首屏 | 独显监控有数据；CPU / 内存 / 存储启动即显示 |
| 毒蝰 V3 极速版（00B8） | 连接后打开设备页 | 设备卡出现，电量 / DPI / 轮询率可读 |
| 灵刃 15 2019（023A，Win10） | 开关键盘灯、切灯效、改颜色、切游戏模式 | 四项都能下发，游戏模式不只亮灯 |

## 反馈格式

- 附 `%LOCALAPPDATA%\OpenSynapse\opensynapse.log`（或诊断页复制出的日志）。
- 写明设备型号 / PID、Windows 版本、操作步骤、期望与实际。
- 写入类问题请附“写入前值 → 写入值 → 回读值”。

## 边界

- 本包只代表代码、manifest 和协议测试对齐；没有对应机型的实机复测。
- 管理员接管只覆盖同一用户会话内、带 shutdown 通道的旧实例；旧实例卡死超过 15 秒会回退到激活旧实例。
- 023A 的 6x16 行序、Wave 方向值和帧方向仍需实机确认。
